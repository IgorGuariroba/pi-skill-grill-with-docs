# pi-skill-grill-with-docs

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-grill-with-docs)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**grill-with-docs** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> A relentless interview to sharpen a plan or design, which also creates docs (ADR's and glossary) as we go.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-grill-with-docs
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-grill-with-docs.git ~/.pi/agent/skills/grill-with-docs

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-grill-with-docs.git ~/.agents/skills/grill-with-docs
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:grill-with-docs
```

Or let Pi automatically route to it based on conversation context and need.
